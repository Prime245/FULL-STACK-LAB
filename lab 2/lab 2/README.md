# Lab 2 — Full Stack Web Development

Open `index.html` in Chrome, Edge, Firefox, or any modern browser. No installation, server, or dependencies are needed. Navigate between all five tasks using the top menu.

1. `timetable.html` — BSCS-V-B (Shift-I) class timetable transcribed from the supplied image.
2. `facebook.html` — Facebook-inspired home page mockup (static, no login or real social features).
3. `portfolio.html` — personal portfolio using Asad Hayat’s shared project details.
4. `ieee-paper.html` — printable IEEE-style *sample layout*, not an official IEEE submission template.
5. `custom-ui.html` — study dashboard with a browser-local checklist.

All pages share `style.css`. The font import uses Google Fonts when connected; Arial fallback works offline. External GitHub links need internet.

To submit: extract this ZIP, place the `lab 2` folder into your GitHub repository, commit and push, then submit the repository URL.
